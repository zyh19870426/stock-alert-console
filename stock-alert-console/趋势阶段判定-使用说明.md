# 趋势阶段判定 · 使用说明

> 2026-09-22 改版。取代原来的「主力博弈 V3 每日投票」成为主结论。

## 一句话定位

**不预测明天涨跌，只回答"这票现在处在什么阶段"。**

回答你最关心的三个问题：
1. 是不是已经进入持续下跌 → 别抱反弹幻想
2. 表现不好是短暂回调还是拉升前深蹲 → 别被洗出去
3. 一直涨是不是真见顶 → 别涨一点就跑，也别见顶了还贪

---

## 六态速查

| 状态 | 颜色 | 触发条件 | 历史实测（300 只大样本） | 你该怎么做 |
|---|---|---|---|---|
| **上涨中继** | 蓝 | 从 60 日低点涨 ≥15%，过热分 ≤1 | 见顶率 20.9%，40 日后中位 **+1.7%** | **拿住**，别涨一点就跑 |
| **过热警戒** | 琥珀 | 过热分 = 2 | 见顶率 31.6% | **减一半**，剩下的设止盈线 |
| **见顶风险** | 橙（整行高亮） | 过热分 = 3 | 见顶率 **44.4%**（基线 25.4%）；40 日后中位 **−9.3%**、期间最大回撤中位 **−19.9%** | **落袋**，别贪最后一段 |
| **健康回调** | 蓝 | 从 60 日高点回落 ≥8%，破位分 ≤1 | **68.0%**（0 分）/ 44.5%（1 分）能在 40 日内涨回高点 95% | **拿住**，是深蹲不是转势 |
| **转势下跌** | 橙（整行高亮） | 破位分 ≥2 | 转势率 **42.3%**（基线 30.2%），只有 23.6% 能涨回 | **撤**，已入下跌通道 |
| **趋势运行中** | 灰 | 其余 | — | 按原计划持有，无需操作 |

### 两个打分卡（各 3 项，各计 1 分）

**破位分** —— 判断"跌下去还能不能回来"
- 跌破 MA60
- 从 60 日高点回落 >15%
- 20 日跌幅 >10%

**过热分** —— 判断"涨上去还能不能继续"
- 20 日涨幅 >20%
- 从 60 日低点涨 >30%
- 当日换手率 >3%

## 与旧版对比

| | 旧（V3 主力博弈） | 新（趋势阶段） |
|---|---|---|
| 标签变化频率 | **相邻日变化 73.2%**（平均 1.4 天换个说法） | **10.8%**，一段状态持续 **9~13 个交易日** |
| 多空直接反转率 | 32.2% | 需连续 2 天确认才切换 |
| 预测力（8 个分支） | 前瞻超额中位全在 ±0.05% 内 = 噪声 | 破位分 0 vs ≥2：转势率 8.8% vs 42.3% |
| 判定依据 | 主力资金流 + 涨跌 + 趋势（三源投票） | 纯价格结构 + 换手率 |
| 主力资金流角色 | **投票源之一** | **不参与判定**（与涨跌 85% 共线，已证伪），仅作参考展示 |

## 怎么用

### 看哪里
- **首页**：每张持仓卡的第一行就是「阶段」，格式 `阶段 → 转势下跌 · 第 5 天`
- **持仓详情**：点进卡片，第一行是「阶段」，下面依次是中长线、主力（参考）、散户、股东

### 怎么判断轻重
- **橙色 + 整行高亮** = 要动手（只有「转势下跌」「见顶风险」两态会高亮）
- **琥珀** = 该做减法了（过热警戒）
- **蓝色** = 拿住（上涨中继 / 健康回调）
- **灰色** = 没事，别自找动作

### 「第 N 天」怎么看
- 显示的是**本状态已经持续了几个交易日**，不是"信号发出了几次"
- 「刚切换」= 今天才变，可以再观察一天（系统本身也要求连续 2 天才确认）
- 天数越长说明状态越稳，不是"过期"

### 一个使用原则
**状态不变就不操作。** 这套设计的目的就是让你不必每天看盘——日频变化率从 73.2% 降到 10.8%，意味着平均一个状态会持续两周左右。

## 严谨说明（必须知道的限制）

1. **破位分只能判"会不会收回"，不能判"跌多深"。**
   实测：破位分≥2 组与全部回落样本的 40 日收益中位是 −1.1% vs −1.2%，几乎无差。
   它的价值是告诉你**别等反弹**，不是告诉你还会跌多少。

2. **过热分的绝对值受市场环境影响大。**
   按年份看：2025 年见顶率 31.5%、2026 年 57.4%——绝对数值浮动很大，但**每一年都高于当年基线**。
   所以它更适合做**相对排序**（"这几只里谁最危险"），而不是绝对阈值。

3. **破位分的绝对阈值是稳的。** 按年份 6/6 年、按个股活跃度三档（43.0/43.1/42.2%）几乎完全一致 —— 可以当绝对阈值用。

4. **样本边界**：300 只票、2021-10 ~ 2026-07。日K 291/300 只只有 2.7 年（腾讯前复权接口上限 641 根）。未覆盖 ST 股、停复牌、2015/2018 极端行情。

5. **换手率缺失时**：过热分自动降级为 2 项判定（2 项里中 2 项也算见顶风险），不会给出残缺结论。

## 附：为什么主力资金流不参与判定了

不是它没用，是**它和"当天涨跌"说的是同一件事**：

- P(主力净流出 | 当天跌) = **85.2%**
- P(主力净流入 | 当天涨) = **78.2%**

两个号称"独立"的源，在 80% 的日子里给出同向答案。所以只要下跌就会凑齐"价跌+主力出"，判定自然一边倒地变成"派发"。

在"是不是进入持续下跌"这个命题下，实测"连续净流出 ≥5 天"的区分度是 **−0.3pp**（等于没有）。

所以它降级为**参考展示**（详情页标「主力（参考）→ X」），算法与函数一字未动，保留可回退。
