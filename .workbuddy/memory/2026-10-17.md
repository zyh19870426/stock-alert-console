## ★★ 第三轮核查：分仓份数是否严格执行（用户问）

### 一、引擎代码事实（`strategy.js`）
- **名额上限严格执行**：`:218 if (positions.length >= P.slots) break`（买入）、`:348 freeSlots = P.slots - positions.length`（选股）、`:366 cands.slice(0, freeSlots)`（`refillOnSkip:false` ⇒ 只挂前 freeSlots 名，弃买空过不补位）
- **★ 但资金分配不是固定 1/N**：`:229 const budget = P.allocMode==='fixed' ? slotBase : Math.floor(cash / freeSlots)`
  而 `BASE.allocMode = 'dynamic'`（`regime.js:17`）⇒ **每份 = 当前可用现金 ÷ 当前空余名额**

### 一、★每笔净收益的精确恒等式（`hist-attrib3.js` 核心，两侧数值严格相等）
```
净收益 = 开盘溢价(gap) + 首日日内(d1) + 后续持有(rest) + 乘法凸性 + 交易成本
  gap = open(T+1)/close(T)-1 ; d1 = close(T+1)/open(T+1)-1 ; rest = 卖价/close(T+1)-1
  乘法凸性 = mean(卖/买-1) - (gap+d1+rest)   ← 加法求和 vs 乘法链接之差
  交易成本 = mean(pnlPct) - mean(卖/买-1)
```
**★口径铁律：三段加法之和不等于净收益 —— 差额=凸性+成本，两者量级都在 0.5~1pp，不可忽略。**
- **B3 全区间（631 笔）净 −1.34% = 溢价 +0.97% − 首日 0.34% − 后续 0.63%（加法小计=+0.00%）− 凸性 0.86% − 成本 0.48%**
- B3 最近窗口（131 笔）净 +2.10% = +1.05% +0.54% +1.59%（小计 +3.17%）− 凸性 0.97% − 成本 0.10%
- B1 全区间 −0.67% = +0.13−0.19−0.21（−0.28%）−0.11−0.29 ；B5 全区间 −1.43% = +0.61−0.14−1.19（−0.72%）−0.37−0.34

### 二、★核心结论
1. **加法小计（买卖点纯价格期望）= +0.00%（B3 全区间）** ⇒ 这套买卖点**零 alpha 映射**（不创造也不消灭 alpha）。全部亏损 = 凸性 + 成本。

### 四、★安慰剂：R1 过不了「随机少交易」这一关
按与 R1 相同的「减少开仓比例」，随机选择哪天不开仓，跑 200 次：

### 五、机制归因（为什么是负的）
1. **周转率下降**：两个名额原本各自滚动（A 卖出当天即用释放名额买新票，B 继续持有）；R1 要求两票都卖光才开，先卖的资金被迫等待。
2. **选股时点被随机化**：原样是「有好票就买」，R1 是「清仓那天有什么买什么」，而清仓日与当日涨停梯队强弱无关 ⇒ 单笔均值同步下降（+1.06%→+0.37%）。
3. **集中度恶化**：3板2份 Top10 占比 160% → 539%，去掉 Top10 后 −342%（原样 −172%）。
4. 逐年最刺眼：**2021 年 3板2份 +31.08% → −16.22%**；2026 年 +212.10% → +120.40%。**R1 专挑好年份下手**（好年份正是滚动复利最值钱的时候）。

### 六、裁决
- **不采纳 R1**（也不采纳 R2：+45.30%，仍远低于原样 +185.70%）。
- 若目标是「锁住利润」，正确工具是**移动止盈 / 缩短持有期 / 分批减仓**，不是「禁止开新仓」——
  后者压缩的是资金周转次数，不是单笔质量。
- 沪深300 闸门已按指令从本轮全部移除（上一轮已证明该窗口内它是 −22~−38pp 的负作用）。

## 二十二、限制创业板名额（maxGem）—— 已上线

脚本 `hist-gem-cap.js` → 报告 `hist/gem-cap.md`。**结论：落地 `maxGem: 1`（2 个名额里最多 1 只创业板）。**

### 结果（全区间）
| 变体 | 收益 | 笔数 | 单笔 | t | 回撤 | 创业板占比 |
|---|---:|---:|---:|---:|---:|---:|
| 不限（改前） | 4383% | 1042 | 0.98% | 3.15 | 47.7% | 36% |
| **最多 1 只创业板** | **5968%** | 1032 | **1.02%** | **3.33** | **44.0%** | 31% |
| 完全剔除 | 1783% | 946 | 0.90% | 2.54 | 54.9% | 0% |

**唯一做到收益↑ / t↑ / 回撤↓ 三项全优的改动。** 主板单笔从 1.13% 升到 **1.27%**（腾出的名额给了更好的主板票）。

### 防伪检验
1. **对称性对照**：限制主板最多 1 只 → 4639%、t 3.04↓、回撤 51.5%↑（变差）⇒ 不是集中度效应。
2. **安慰剂（关键）**：按代码字符和奇偶切「随机半区」并限制最多 1 只 → **3484%（−20%）、t 3.01↓、回撤 50.3%↑**，12 格网格 **0/12** 胜过现状。
   ⇒ 限制任意一半有害、限制创业板有益，方向相反 ⇒ 效应来自创业板本身。
3. **前后半段样本外**：867→1137%、391→419%，两半都赢。
4. **固定 q=0.80 扫 trail 21~29：9/9 全胜，t 每一格都提升**。
5. **压力测试**：创业板单笔每一档冲击下 maxGem=1 都优于现状；盈亏平衡点 −1.57% → **−2.31%**（安全边际 2.30pp → 2.79pp）。

### 已知瑕疵（必须记住）
- **q ≥ 0.82 时 maxGem=1 有断崖**（−1651 ~ −3624pp）。线上 q=0.80 安全；**以后若要调 gateYz.q，必须重跑本项检验**。
- 滚动 2 年窗口只 4/8、逐年账户口径 3/7。但**安慰剂同口径也是 3/8 和 3/7、完全剔除（全区间最差）反而 5/8** ⇒ 短窗口切断复利后判别力天然不足，不作为决定性证据。
