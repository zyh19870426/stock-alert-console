## 一句话答案

**两边都成立 —— 而且个股上比大盘更明显。我上一轮的结论错了，错在测的是「横截面」而这个问题是「时序」。**

| | 大盘（沪深300） | 个股（131 只） |
|---|---|---|
| **出清 → 后续** | ✅ 余额距500日高点回撤 ≤−30%：未来60日 **+2.54%**，上涨占比 **72.6%**（基准 52.7%） | ✅ 余额距250日高点回撤 ≤−30%：未来60日 **+4.62%**，120日 **+8.15%**（基准 +2.90% / +4.99%） |
| **暴增 → 后续** | ✅ 20日余额猛增 ≥+10%：未来60日 **−4.91%**，上涨占比 **33.6%**（基准 52.7%）<br>杠杆率 >3.0%：**−1.09%**，上涨占比 **34.0%**<br>杠杆率全历史分位 >90%：**−0.52%**，上涨占比 **32.6%** | ✅ 余额仍贴着自己近期高点（未出清）：未来60日 **−0.57%**，上涨占比 **39.3%**<br>（基准 +2.90% / 47.1%） |

**我上一轮为什么得出"个股不成立"**：那次测的是**同一天把 131 只票互相排序**（横截面）。在横截面里，"余额增得多"往往只是**"这只票已经在涨"的同步结果**，而且不同股票处在各自的杠杆周期不同位置，比大小没有意义。**"出清/暴增"是同一只票自己跟自己比的时序概念** —— 换成时序口径，效应立刻出现，而且四档完全单调。

**大盘上一个额外教训**：口径必须选对。v1 用「滚动750日分位」测大盘，什么也没测出来 —— 因为在长期的杠杆上行期里，">90% 分位"会连续持续很久（780 个观测，占 26%），它测的其实是"杠杆上行期"而不是"极值"。换成**距500日高点回撤**或**绝对水平**，效应立刻清楚。

## 二、大盘（沪深300）：三种口径全表（未来60日）

| 口径 | 分档 → 未来60日收益 / 上涨占比 |
|---|---|
| ① 余额距500日高点回撤（**出清**） | **≤−30%：+2.54%（72.6%）** ｜ −30~−20%：+3.22%（46.7%）｜ −20~−10%：+0.47%（49.5%）｜ −10~0%：+0.32%（46.6%）｜ 基准 +0.93%（52.7%） |
| ③ 杠杆率**绝对水平** | <1.5%：— ｜ 1.5~2.0%：+3.53%（42.0%）｜ 2.0~2.5%：+1.28%（53.8%）｜ **2.5~3.0%：−1.11%（55.0%）** ｜ **>3.0%：−1.09%（34.0%）** |
| ④ 杠杆率**全历史分位** | 10~30%：+0.80%（35.9%）｜ 30~70%：+0.85%（53.8%）｜ 70~90%：+1.54%（62.3%）｜ **>90%：−0.52%（32.6%）** |
| ⑤ 20日余额变化（**加/去杠杆速度**） | **≤−10%：+2.81%（67.4%）** ｜ −10~−3%：+2.11%（64.2%）｜ ±3%：+1.55%（54.9%）｜ +3~+10%：+0.29%（43.5%）｜ **≥+10%：−4.91%（33.6%）** |

⑤ 是最干净的一条：**杠杆加得最猛的那一档，未来 60 日平均 −4.91%、只有 33.6% 上涨**（基准 52.7%）。
反向的"踩踏式去杠杆"（20 日余额掉 10% 以上）反而 **+2.81%、67.4% 上涨**。

⚠️ **但"出清"不是即时信号 —— 它是渐进的**。2015 年 7 次快速去杠杆事件：

| 时点 | 余额20日 | 之后60日沪深300 |
|---|---|---|
| 2015-07-03 | −11.9% | **−18.20%** |
| 2015-08-03 | −26.9% | **−5.24%** |
| 2015-09-01 | −22.7% | +11.52% |
| 2016-01-12 | −10.5% | +1.42% |
| 2016-02-01 | −22.5% | +10.63% |
| 2016-03-01 | −10.8% | +4.56% |
| 2024-02-05 | −10.1% | +14.27% |

→ 头两次（2015-07、2015-08）**还在跌**，第 3 次起才转正，7 次均值 +2.71%。
**"出清"是个过程，不是一天的事件；踩踏中间还会继续踩。**

## 三、个股（131 只）：出清/暴增成立，而且不是"跌多了反弹"的影子

### 3.1 出清程度 dd250（余额距近250日高点的回撤）→ 单调

| 分档 | ≤−30% | −30~−20% | −20~−10% | −10~0% | 基准 |
|---|---|---|---|---|---|
| 未来60日 | **+4.62%** | +3.54% | +1.79% | **−0.57%** | +2.90% |
| 上涨占比 | 50.8% | 48.6% | 44.9% | **39.3%** | 47.1% |
| 未来120日 | **+8.15%** | +5.32% | +2.79% | **−0.35%** | +4.99% |

**完全单调**：余额离自己的近期高点越远（出清越彻底），后续越好；**贴着高点（杠杆还在里面）= 后续最差**。
这就是你说的"资金过度接盘"在个股上的正确表现形式 —— 但它**不是**由"杠杆占比高低"决定的。

### 3.2 是不是只是"跌多了反弹"？—— 三重检验，都不是

| 检验 | 结果 |
|---|---|
| **双重排序**：先按「自己过去60日涨跌」分5组，组内比出清多 vs 出清少 | 五格差异 **+3.52 / +3.25 / +3.93 / +3.16 / +3.92%**，**5/5 全为正**，均值 **+3.56%**<br>⇒ 在任何价格状态下，出清多都对应更好的后续收益 |
| **正交化**：dd250 对 [自己过去60日涨跌, 过去120日涨跌, 换手率] 回归取残差 | 残差 Q1(出清多) − Q5(出清少) = **+2.08%，仍有独立信息 ✅**<br>具体形态：**加杠杆最猛的那一档（Q5）未来60日只有 +1.12%，其余四档 +3.1~3.7%** |
| **去杠杆度** ddGap = 余额回撤 − 股价回撤 | **≤−20%（余额比股价抗跌 = 杠杆死扛）→ 未来60日 −0.14%、120日 −0.79%，上涨占比 42.6%（最差）**<br>**≥+20%（余额跌得比股价快 = 真去杠杆）→ +3.18% / +5.85%，上涨占比 57.3%（最好）** |

**ddGap 这条最可解释，也最好用**：
> 股价跌了但**融资余额没跑**（余额抗跌）→ 杠杆盘还在死扛，后面往往继续阴跌；
> **融资余额跑得比股价还快**（真去杠杆）→ 该跑的杠杆都跑了，后面反而好。

### 3.3 "个股杠杆占比高 = 过度接盘"？—— 恰恰相反

用真实流通市值算的杠杆占比分布：**中位 3.57%，10/90 分位 1.07% / 7.08%，最大 15.21%**（全市场只有 2.6%）。
按占比水平分层 → 未来60日：<1% **−0.24%** ｜ 1~2% +0.28% ｜ 2~4% +2.81% ｜ 4~8% +4.34% ｜ **>8% +5.13%**
→ **占比越高，后续反而越好，单调递增**。所以"占比高 = 危险"不成立 ——
高占比基本是**小盘活跃股**的代理（小盘股在这段样本期本来就走得好），不是杠杆风险。

**但"出清后弹性"确实随杠杆占比放大**（未来60日）：

| | 余额贴着高点（未出清） | 已出清 >20% |
|---|---|---|
| 低杠杆占比 <4% | −1.30%（上涨占比 38.9%） | +2.67%（50.0%） |
| 高杠杆占比 ≥4% | −1.11%（39.4%） | **+6.98%（50.2%）** |

→ **杠杆占比越高，"出清"之后的反弹幅度越大**（+6.98% vs +2.67%）。
→ 而"余额还在高位"这个负面状态，在两档里都成立（−1.1~−1.3%，上涨占比仅 39%）。

### 3.4 稳健性（逐年，防"只靠 2024-09 那波"）

| 年份 | 基准 | ≤−30% | −10~0% | 出清多−少 |
|---|---|---|---|---|
| 2023 | −7.34% | −7.63% | −8.36% | +0.72% ✅ |
| 2024 | +4.79% | +7.43% | −0.90% | +8.33% ✅ |
| 2025 | +5.96% | +7.19% | +2.45% | +4.74% ✅ |
| 2026（至8月） | −4.91% | −7.56% | −3.62% | −3.94% ❌ |

**剔除 2024-09~12 那波大反转后，效应仍有 +3.60%**（全样本 +5.19%）⇒ 不是单靠一波行情。
但 **2026 年是反向的**（下跌市里出清股跌得更多 = 左侧还在下跌中继），**4 年里 3 年成立**。

## 四、所以：为什么大盘要看"水平"，个股要看"位置"

| | 大盘（全市场） | 个股 |
|---|---|---|
| 杠杆率的量级 | **2.6%**（相对流通市值） | 中位 **3.6%**，高的到 **15%** |
| "余额高"意味着 | **全市场都在用杠杆** → 系统性风险敞口，出事是踩踏（2015） | **这只票活跃/弹性大** → 更多是股票风格的代理，不必然是风险 |
| 有效的判据 | **水平 / 速度**（绝对水平 >3%、20日猛增 ≥10%、全历史分位 >90%） | **位置**（相对自己近250日高点是否已出清）+ **余额与股价谁跑得快**（ddGap） |
| 为什么 | 全市场杠杆是**总量**概念，加满就加不动了，且强平是连锁的 | 单只票的杠杆占比受流通盘、活跃度影响太大，**绝对水平不可比**；只有"相对自己"才可比 |

一句话：**大盘的"杠杆暴增"是"大家都借满钱了"；个股的"杠杆占比高"往往只是"这只票很活跃"。**
所以大盘看水平、个股看位置 —— 用错维度就会得出"个股不成立"的错误结论（我上一轮就是这么错的）。

## 五、对控制台的可落地改法

现在「两融」那一行的四象限定性，第一维用的是**20 日余额变化方向**（增/减）。按本次结论，**更该用的是"余额相对自己近 250 日高点的位置"**：

| 状态（建议） | 判据 | 统计依据（未来60日 / 120日） |
|---|---|---|
| **杠杆已出清** | dd250 ≤ −20% | +4.3% / +7.3%（上涨占比 ~50%） |
| 出清中 | −20% < dd250 ≤ −10% | +1.8% / +2.8% |
| **杠杆仍在高位** | dd250 > −10% | **−0.57% / −0.35%**（上涨占比 39.3%） |

并可加一条更细的（数据最干净）：
- **余额比股价跌得快**（ddGap ≥ +20%）→ 真去杠杆，后续偏好（60日 +3.18%、120日 +5.85%、上涨占比 57.3%）
- **余额比股价抗跌**（ddGap ≤ −20%）→ 杠杆死扛，后续偏差（120日 −0.79%、上涨占比 42.6%）

⚠️ 前提提醒：这是**状态描述 + 概率倾向**，不是择时信号（60 日尺度、4.3% vs −0.6% 的差、且 4 年里 3 年成立）。
仍应与「阶段判定」并列展示，不要替代它。**两融行保持纯展示（不进任何判定公式）这条不变。**

## 六、局限

- 个股样本期 4 年（两融接口单只上限 1000 交易日），大盘 13.5 年；个股 4 年里 2026 年与结论反向。
- 杠杆占比用「今日流通市值 ÷ 今日收盘」倒推流通股数、再乘当日收盘 ⇒ 未考虑 4 年内的送转/增发，个别票会有偏差。
- 大盘观测高度时序自相关（重叠观测），非重叠抽样后每组只剩个位数样本 ⇒ 大盘那几张表只宜看方向，不宜看精确幅度。
- `dd250` 的 ≤−30% 档占个股样本 43%，分档不均衡。
