## 为什么单因子残差显著、合成却无效？

1. **残差检验考的是单调性，总分考的是 40/60 分组**。bdNH/fqi 的独立信息集中在分布尾部，不改变阈值附近的分组归属，对前瞻价差贡献≈0。
2. **信息大部分已被捕获**：bdNH↔mom 0.51、fqi↔mbs 0.45/↔mgn 0.53，进合成后 12~25% 权重的独立增量被稀释。
3. **副作用实打实**：日均|Δ| 4.54→4.73~5.40（更躁）、极度恐惧区 8%→6%（轻微收敛，方向同 v2 加 pan 的教训）。

## 与 pan（v2 已加）的本质区别

| | pan | bdNH / fqi |
|---|---|---|
| 加入理由 | 描述正确性（恐慌日读 84.7 极度贪婪是错误描述）+ 硬约束 pan≤25⇒总分≤38 | 仅"多一个有残差显著性的因子" |
| 改变分组行为 | 是（2.9% 交易日强制入恐惧区） | 否（阈值附近样本不变） |
| 前瞻区分度 | 不变坏（诚实披露：无独立预测力） | **非重叠价差 2.17%→0.72~1.96%，变坏** |

**裁决**：加因子必须有机制性用途（像 pan 的硬约束），"残差显著"本身不构成加入理由。
